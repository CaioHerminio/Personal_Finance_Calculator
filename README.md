# 💰 Personal Finance Calculator

A simple console-based personal finance calculator written in C++. This project allows users to distribute their monthly salary across different financial categories and calculate their total budget allocation and remaining balance.

![Personal Finance Calculator Banner](banner.png)

## 📌 About the Project

The **Personal Finance Calculator** is a beginner C++ project created to practice fundamental programming concepts through a practical application.

The program asks the user to enter their monthly salary and choose what percentage of their income they want to allocate to five categories: necessities, investments, savings, studies, and leisure.

It then calculates the monetary value assigned to each category, the total percentage allocated, and the remaining balance.

## ✨ Features

- 💵 Input a monthly salary
- 🏠 Allocate a percentage to necessities
- 📈 Allocate a percentage to investments
- 🏦 Allocate a percentage to savings
- 📚 Allocate a percentage to studies
- 🎮 Allocate a percentage to leisure
- 🧮 Calculate the amount allocated to each category
- 📊 Display the total percentage allocated
- 💰 Calculate the remaining balance

## 🛠️ Technologies

- **Language:** C++
- **Standard Library:** `<iostream>`
- **Interface:** Command-line interface (CLI)
